<h1 align="center">Single Cat for Craft CMS</h1>

Single Cat is a Craft CMS plugin that gives authors a compact dropdown when a content model needs exactly one category. Keep the relationship native to Craft without presenting a full element selector for a small, deliberate choice.

Choose the category group for the field and present its categories in a dropdown. Authors get a quick, familiar control with no ambiguity about selecting several values.

## Features

- Store the selected value as a native Craft category.
- Choose from the configured group without opening an element modal.
- Match content models that require exactly one category choice.
- Limit the options to the taxonomy that belongs in the field.
- Use the chosen category's fields and URL in normal templates.
- Query the selected category as a native element in headless builds.
- Add the field to Craft layouts alongside the rest of the content model.
